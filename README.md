# 图书借阅可视分析系统（web2）

基于 **D3.js** 的单页联动分析系统，面向上海图书馆体系借阅行为的多维度探索与可视化呈现。

---

## 数据来源与声明

本系统基于 **第十一届上海图书馆开放数据竞赛** 发布的 **官方开放数据集** 进行清洗、聚合与可视化创作。

- 原始数据经本地清洗后保存为 `data/fact_loan.parquet`（全库约 6.9 万条借阅记录，时间范围为 **2025 年**）。
- 前端使用精简列式 JSON `fact_slim.json` 加载，字段涵盖馆点、时间、人群、馆藏与中图法类目等维度。


**说明：** 数据使用权归竞赛主办方及数据提供方所有；本系统仅作分析与展示用途，公开部署时请注意读者隐私与数据合规。

## 系统概述

系统采用 **左侧控制栏 + 右侧主分析区** 布局，以 **2025 十二个月借阅热力日历** 为核心枢纽，支持馆点、时间、人群、类别等多维筛选，各图表之间可 **点击联动**，用于发现「谁在何时、何地、借了什么」的规律。

顶部展示当前筛选状态、筛选后借阅量与全量规模，并支持 **一键重置** 全部选择。

默认分析口径：**排除期刊** 且 **排除年龄异常标记** 后的借阅记录（与热力图及主联动图表一致）。

## 功能说明

### 1. 馆点图例（左侧栏）

- **大类筛选**：中心馆、区级分馆、街镇馆、其他网点等；点击「全部大类」恢复。
- **二级馆名**：展示各馆点借阅量，点击可筛选至单一馆点；「全部馆点」恢复合计。
- 大类与馆点为 **层级联动**：选大类后，二级列表仅显示该大类下馆点。

### 2. 节假日设置（左侧栏）

- 预置 2025 年主要法定节假日（元旦、春节、清明、劳动节、端午、国庆中秋等）。
- 勾选/取消勾选：控制热力日历中 **节假日日期** 是否高亮。
- 支持 **自定义日期 + 节日名称** 添加本地节假日（保存在浏览器 `localStorage`）。
- 热力日历表现：
  - **普通日期**：矩形日格，黄→深红色阶表示借阅量。
  - **节假日**：**六边形**日格 + 紫色描边。
  - **周六、周日列**：浅色纵向背景。
  - 全年借阅最高月，月合计前显示 **🔥** 标识。

### 3. 个性化阅读账单（左侧栏）

- 输入 **读者编号** 生成 **2025 年度个人阅读账单**（弹层展示，可打印/保存）。
- 支持 **随机一位读者**、**借阅达人快捷入口**（全年借阅 Top 榜）。
- 账单内容包含：全年借阅次数、超越读者百分比、阅读人格标签、最爱馆点/类别/作者、活跃月份、高峰月与时段、月度/时段小图、年度书单 Top5 等。

### 4. 2025 十二个月借阅热力日历（核心图表）

- 每月一行，按 **周一→周日** 列对齐；顶部分星期表头循环标注。
- **点击月名**：联动下方图表至 **该月**（河流图按日展开；每周哪天最忙显示该月 **周平均**）。
- **点击日格**：联动至 **该日**（时段分布显示当日小时分布；河流图按小时展开）。
- 再次点击同一月名/日格可 **取消** 该时间筛选。
- 鼠标悬停：**横纵十字高亮** +  tooltip（日期、星期、借阅量、节假日名称）。
- 受 **馆点筛选** 与 **图表联动筛选**（人群、类别、星期、时段等）共同影响，用于观察特定群体在全年哪些日期更活跃。

### 5. 时段分布

- 默认：**全年小时合计**（7:00–21:00 柱状图），高峰时段标 **★**。
- 点击热力图 **某一天** 后：切换为 **当日小时分布**。
- 点击某一 **小时柱**：在全页叠加 **时段筛选**（与人群、类别等筛选可组合）。
- 再次点击同一柱可取消时段筛选。

### 6. 每周哪天最忙

- 柱状图 + 底部 **忙碌星级**（1–5 星）。
- 默认：全年各星期合计。
- 点击热力图 **月份**（未选具体日）：显示该月 **周平均** 各星期几借阅量。
- 点击柱子：筛选该 **星期几**，联动热力日历与其他图表。

### 7. 借阅河流图

- 中图法 Top 类别 **河流图**（wiggle 堆叠），顶部 **色块图例** 可悬停高亮。
- **点击图例类别**：筛选该中图法大类，联动全页。
- 时间粒度随热力图选择变化：
  - 默认：**全年 × 12 个月**
  - 选月：**该月 × 各日**
  - 选日：**该日 × 各小时**

### 8. 年龄 × 类目关联（热力矩阵）

- 年龄段 × 中图法 Top 类目的 **关联热力格**。
- **点击格子**：同时筛选 **年龄段 + 中图法类别**（交叉人群）。
- 再次点击同一格取消两项筛选。

### 9. 人群分布（双雷达图）

- **左侧：性别（占比）** — 雷达按 0–100% 缩放，轴标签显示占比。
- **右侧：年龄** — 各年龄段借阅量雷达。
- **点击雷达上的点**：筛选性别或年龄段，热力日历与时段等图表同步更新，便于观察该人群 **集中出现的日期与时段**。
- 再次点击可取消对应筛选。

### 10. 图书类别（中图法）

- 条形图 + **热度星级**；点击条形筛选该 **中图法大类**。

### 11. 出借图书类别

- **异形图例**（圆、方、菱形等），大小表示借阅量；点击筛选 **馆藏类型**。

### 12. 图书出版年份

- 面积折线图，**近 3 年**区间浅底标注。
- 点击圆点筛选该 **出版年**。

### 13. 热门出版社 / 作者 / 书名 Top 榜

- 星级热度排行条形图。
- 点击行筛选对应 **出版社**、**作者** 或 **书名**（Top20 书名榜）。

### 14. 全页图表交叉联动

除馆点与时间外，支持多维 **可叠加 / 可取消** 筛选：

| 筛选维度 | 触发方式 |
|----------|----------|
| 性别 | 人群雷达（左） |
| 年龄段 | 人群雷达（右） |
| 中图法类别 | 类目条形 / 河流图图例 / 关联矩阵 |
| 馆藏类型 | 出借类别异形图 |
| 星期几 | 每周哪天最忙柱图 |
| 时段（小时） | 时段分布柱图 |
| 出版年 | 出版年折线图 |
| 出版社 / 作者 / 书名 | 对应排行榜 |

- 顶部 **「图表联动筛选」** 标签栏展示当前已选维度，点击 **×** 可单独清除。
- **重置全部选择** 清空馆点、时间、人群、类别等全部条件。
- 各图表在展示本维度时保留 **对比上下文**（例如已选「男性」后，性别雷达仍显示男女结构，其他图表按筛选结果更新）。

## 技术架构

| 层级 | 说明 |
|------|------|
| 前端 | HTML5 + CSS3 + D3.js（`static/vendor/d3.min.js`） |
| 状态管理 | `AppState`（馆点、时间、交叉筛选） |
| 图表模块 | `charts.js`（全部 D3 可视化） |
| 阅读账单 | `reader-bill.js` |
| 节假日 | `holidays.js` + `data/holidays.json` |
| 本地服务 | Flask `server.py`（仅静态资源与 JSON，端口 **8060**） |
| 线上部署 | GitHub Pages + GitHub Actions（`prepare_pages.py` 构建 `docs/`） |

### 目录结构

```
web2/
├── server.py              # 本地 Flask 服务
├── export_slim.py         # 从 parquet 导出 fact_slim.json
├── prepare_pages.py       # 构建 GitHub Pages 用 docs/
├── data/
│   ├── fact_slim.json     # 前端主数据（约 6.7MB）
│   └── holidays.json      # 默认节假日配置
├── static/                # 开发与本地服务静态资源
│   ├── index.html
│   ├── css/style.css
│   └── js/                # data, state, charts, holidays, reader-bill, main
├── docs/                  # Pages 发布目录（可由脚本生成）
├── .github/workflows/     # 自动部署 Pages
├── DEPLOY_GITHUB.md       # GitHub 发布详细步骤
└── README.md              # 本文档
```

## 本地运行

### 环境要求

- Python 3.8+
- 已清洗数据：`d:\Z_ST\data\fact_loan.parquet`（或修改 `export_slim.py` 中路径）

### 步骤

```bash
# 1. 导出前端数据（数据更新时执行）
python d:\Z_ST\web2\export_slim.py

# 2. 启动服务
python d:\Z_ST\web2\server.py
```

浏览器访问：**http://127.0.0.1:8060**

健康检查：`http://127.0.0.1:8060/api/health`

## 数据字段说明（fact_slim 展开后）

| 字段 | 含义 |
|------|------|
| `date` / `month` / `hour` / `dow` | 借阅日期、月份、小时、星期（0=周一） |
| `lib` / `libType` / `region` | 馆点名称、馆点大类、区域 |
| `clc` | 中图法大类 |
| `itemType` | 馆藏/出借类型 |
| `title` / `author` / `publisher` / `pubYear` | 书目信息 |
| `gender` / `ageBand` | 读者性别、年龄段 |
| `rid` | 读者编号（阅读账单用） |
| `peri` | 是否期刊 |
| `ageOutlier` | 年龄异常标记 |
